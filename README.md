# Bunny Studios website

Open index.html. English and Czech publisher, product and documentation pages are included.

## Publish manually / Ruční zveřejnění

Follow DEPLOY_EN.html or DEPLOY_CZ.html. Upload only website contents to a separate repository root. Exclude .qa. Keep .nojekyll. Settings → Pages → Deploy from a branch → main → /(root). Nothing has been published automatically.

Doplňte veřejný kontakt v index.html a cs/index.html. Nahrajte pouze web, nikdy nadřazenou složku nebo Unity projekt. Vynechte .qa.
