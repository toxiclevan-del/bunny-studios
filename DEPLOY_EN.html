Manual GitHub Pages deployment

This is a static website. Nothing has been published or uploaded to an account.

  1. Add your public contact email to both homepages. Confirm that every file you upload is intended to be public.
  2. Manually create a separate website repository. Upload the website folder’s contents to its root, including .nojekyll. Exclude .qa. Never upload the parent folder or a Unity project.
  3. On GitHub open Settings → Pages → Build and deployment → Source: Deploy from a branch. Select main and /(root), then Save.
  4. When deployment finishes, open the address shown in Pages. Check EN/CZ, documentation, images and mobile layout. Preserve filenames and path capitalization.
All paths are relative; repository subdirectory hosting is supported. Open index.html locally. GitHub Pages does not make uploaded files private.
