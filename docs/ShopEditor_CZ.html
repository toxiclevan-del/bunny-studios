Instalace a kontrola závislostí — RC.4

EDITOR OBCHODU — pole a pracovní postupy

Otevření a výběr katalogu

Použijte Tools > NOMAD > Shop Editor. Okno má titul NOMAD Shop. Přepínač České rozhraní / Czech editor mění názvy akcí editoru; obecná serializovaná pole zůstávají anglicky podle Unity. Nemění jazyk runtime UI. Tlačítka Otevřít dokumentaci, Rychlý start a Integrační příručka nahoře otevírají odpovídající lokální české/anglické HTML.

Přetáhněte existující NomadCatalog do Katalog, případně použijte kolečko výběru objektu. Jde o běžné pole Unity, ne automatický prohlížeč katalogů. Nový asset vytvoří Vytvořit samostatný katalog; zvolte jedinečnou cestu .asset a uložte. Nový katalog nemá kategorie ani položky. Při kopírování katalogu pro jiného obchodníka vědomě přidělte nové ID katalogu; zkopírovaná ID sdílejí klíče historie v jedné službě.

Pole katalogu

FieldSkutečný účinek
IDStálá identita katalogu pro klíče zásob/historie; generuje se jednou. Po nákupech či uložení ji neměňte.
Currency IDStrojový identifikátor, výchozí credits. Musí přesně odpovídat IShopWallet.CurrencyID; přejmenování měny tento údaj nemění. Jeden typ měny na katalog/peněženku služby.
Default LanguageKód čtený NomadDemo při Start. Vlastní host musí sám nastavit view.Language. Používejte en / cs, nikoli cz.
Title / Vendor / CurrencyLokalizovaný nadpis, podnadpis prodejce a zobrazovaný název měny. Rozbalte každý oddíl a upravte jazyky.
LocalizationVolitelná tabulka NomadLocalization pro fráze UI. Přiřaďte dodanou nebo vytvořte vlastní přes Tools > NOMAD > Create UI Localization.
Preview LayerČíslo 8–31; vyhraďte jinak nepoužitou vrstvu. Při náhledu se dočasně skryje existujícím herním kamerám. Fyzikální matice se nemění.
LanguagesSeřazený seznam pro jazykové tlačítko za běhu. Zahrňte en a cs; další kódy doplňte i do překladů obsahu a UI.

Kategorie: vytvoření, název, pořadí, viditelnost, odstranění

Klikněte na + Přidat kategorii a její řádek. Rozbalte definici vybrané kategorie (záhlaví s jejím ID, případně Element) a Name. Každý překlad má Language code / Kód jazyka a textovou oblast. Vyplňte en / anglický název a cs / český název. Řádek používá jazyk zvolený v editoru. ID se vygenerují a při přejmenování zůstávají.

Tlačítka ↑ / ↓ posunou kategorii o jednu pozici; runtime záložky toto pořadí respektují. Po přesunu znovu vyberte požadovaný řádek. Vypnutím Visible skryjete runtime záložku, data a položky zůstanou. Jde o zobrazení, nikoli autorizaci nákupu: vlastní backend či API musí mít vlastní pravidla.

Odebrat kategorii (položky přesunout do první zbývající) před odstraněním přeřadí položky do první zbývající kategorie. Poslední kategorii obsahující položky odstranit nelze; nejprve odstraňte položky nebo vytvořte náhradní kategorii. Není zde dialog hromadného mazání. Kde je podporováno, použijte Unity Undo a pak Uložit katalog. Před strukturálními změnami katalog zálohujte.

Položky: vytvoření, úprava, přeřazení, odstranění

Klikněte na + Přidat předmět, vyberte řádek a rozbalte definici (záhlaví s ID, případně Element). Nový předmět patří první kategorii. V Přiřadit kategorii pod jeho vlastnostmi vyberte správnou. Editor vypisuje všechny položky bez ohledu na kategorii. Přejmenovávejte překlady Name, ne ID. V Preview jsou 3D nastavení, ve Stats zobrazované statistiky. Odebrat vybraný předmět odstraní definici; nevrací peníze ani neodebírá již vlastněné kusy z herního inventáře.

FieldSkutečný účinek
ID / Category IDStálá identita předmětu / vazba kategorie. Používejte Assign category místo psaní ID. Změna Name je bezpečná; změna ID oddělí vlastnictví.
Name / DescriptionLokalizovaný název a popis zobrazené v prostředním sloupci.
Rarity / Unlock ID / Equipment SlotMetadata integrace. Rarity a slot nemají vestavěný herní účinek. Neprázdné UnlockID bez IShopPurchaseRule blokuje nákup; dodané pravidlo musí vynucovat jeho význam.
Requirements / LevelPopisná metadata, ne automatická podmínka úrovně postavy. Kontrolu napište do pravidla nebo backendu. Aktuální ShopView nezobrazuje Requirements jako samostatný panel podmínek.
Icon / Gameplay ItemSprite pro seznam/záložní ikonu / volitelný odkaz na herní objekt. Core GameplayItem automaticky nespawnuje ani nevybavuje; vyhodnocuje jej adaptér inventáře.
Price / QuantityKladná celá čísla (minimum 1). Price je celkový odpočet za dodávku; Quantity počet přidaných kusů, ne volič množství. Nákupy za nulovou cenu nejsou podporovány.
AvailableVypnutí zakáže nákup, ale položka zůstane v kategorii viditelná. Nejde o skrytí položky.
EquippablePo vlastnictví povolí EQUIP ITEM a volá backend.Equip. Skutečné vybavení řeší adaptér.
Max PurchasesPočet úspěšných dodávek pro katalog/předmět v této instanci ShopTransactions. Výchozí 1; 0 neomezeně. Není to počet kusů ani trvalá historie účtu.
Stock-1 neomezeně; 0 nedostupné; kladné číslo omezuje dodávky pro službu/katalog/předmět. Číslo v assetu katalogu se neodečítá.
StatsSeznam lokalizovaných Label a textových Value v pravém sloupci. Hodnoty jsou text, ne aplikované herní modifikátory.

Pole náhledu

FieldSkutečný účinek
PrefabPrefab z Project s MeshRenderer+MeshFilter nebo SkinnedMeshRenderer. Kopírují se pouze vykreslovaná data.
RotationPočáteční Eulerovy úhly X/Y/Z ve stupních aplikované na normalizovaný model. Začněte (0,25,0).
Scale0,2–1 relativní vyplnění náhledu; 1 využije bezpečný rámeček, 0,5 je menší. Nejde o metry ani herní velikost.
Target OffsetPosun cíle kamery v normalizovaných jednotkách, délka omezena na 2. Držte poblíž nuly; velké hodnoty mohou model vychýlit.
Camera Size0 používá automatické rámování; kladná hodnota do 10 určuje minimum ortografického rámu. Vyšší hodnota model zmenšuje. Auto-fit může rám dále zvětšit proti ořezu.
Auto Rotate Speed0–60 stupňů/sekundu; 0 vypíná automatické otáčení. Výchozí 10. Obnoví se 1,75 s po uvolnění/resetu.
Zoom Min / Zoom MaxNásobky rámování kamery, výchozí 0,9 / 2,2. Nižší je blíž, vyšší dál. Min musí být <= max. Rozsahy Inspectoru 0,88–1 / 1–4.

Uložení, validace a ověření

Tlačítko Uložit katalog dole uloží vybraný asset. Ověřit katalog otevře dialog: Katalog je platný znamená neprázdná/jedinečná ID, existující kategorie položek a kladné ceny/množství. Netestuje úplnost překladů, modely/materiály, vstupy, měnu peněženky, vybavení ani ukládání na disk. Katalog vyzkoušejte ve vlastní kopii dema. Při změně nastavení právě vybraného náhledu v Play může být nutné vybrat jinou položku a vrátit se, protože viewer uchovává item/prefab v cache; nastavení raději provádějte mimo Play.

Tools > NOMAD > Create UI Localization vytvoří samostatnou tabulku UI. Tools > NOMAD > Create Own Demo Assets je pomocník pro vývojářské znovuvytvoření dema, ne běžný rychlý start; existující demo katalog nepřepíše. Použijte dodané demo.
