Dependency installation and publishing — RC.4

Required packages and tested configuration

Unity 6000.6.3f1. Runtime UGUI: com.unity.ugui 2.6.0 (assembly UnityEngine.UI, including EventSystems). Demo input: com.unity.inputsystem 1.20.0. Supplied model materials and tested demo rendering: com.unity.render-pipelines.universal 17.6.0. Standard animation/physics modules: 1.0.0. Runtime does not directly reference the Input System or URP assembly; the supplied complete product/demo still requires them. Engine modules are installed from Unity, not copied into this product.

Importing the official dependency-aware release

Import the complete official archive through Assets > Import Package > Custom Package. Accept Unity's package dependency installation/update prompt after reviewing its package list. Wait for Package Manager resolution and script compilation. A working network connection or the required Unity registry packages in your local cache is needed. Declining the dependency installation, manually extracting only Assets, or importing an old archive without dependency metadata cannot provide the required assemblies. Do not ignore resulting compiler errors.

The archive includes official packagemanagermanifest/asset metadata declaring only the five packages above. This is different from Assets/NomadShop/package.json: a package.json under Assets is documentation/UPM metadata, not an active project manifest and does not by itself install anything. It is also different from AssetDatabase asset dependency expansion, which can copy unrelated game assets. No UGUI, Input System or URP source is bundled.

Inspecting and recovering

Open Tools > NOMAD > Dependency Status. This separate Editor-only assembly depends on neither Core nor those optional assemblies. It reports installed/missing packages, differences from tested versions and whether an effective URP asset is active. It never silently installs, upgrades, downgrades or edits global settings. If missing dependencies prevent Unity domain reload, restore packages through Package Manager first; an Editor script cannot be relied upon to repair an already broken compilation.

Open Window > Package Management > Package Manager, choose Install package by name, and install each missing package using the identifiers/versions above. Review existing package versions before changing them; do not blindly downgrade an established project. Then wait for compilation and reopen the status window. An installed but different version is not automatically certified compatible.

Installing URP does NOT select an active pipeline asset. For the supplied demo, configure a URP asset in Graphics and any Quality override using your normal project workflow. This package does not replace those settings. Set Active Input Handling to Input System Package (New) or Both for the demo, preserving existing game input needs. The status window explains this input requirement but does not certify the actual action-map configuration. See the full Quick Start and troubleshooting manuals. Demo behavior still requires an EventSystem with InputSystemUIInputModule.
