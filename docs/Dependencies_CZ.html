Instalace závislostí a vydávání — RC.4

Potřebné balíčky a otestované nastavení

Unity 6000.6.3f1. Runtime UGUI: com.unity.ugui 2.6.0 (assembly UnityEngine.UI včetně EventSystems). Demo vstupy: com.unity.inputsystem 1.20.0. Dodané materiály a otestované vykreslování dema: com.unity.render-pipelines.universal 17.6.0. Standardní moduly animace/fyziky: 1.0.0. Runtime přímo neodkazuje na assembly Input System či URP; úplný dodaný produkt/demo je přesto potřebuje. Moduly dodává Unity, jejich zdroje nejsou přibalené.

Import oficiálního archivu se závislostmi

Celý oficiální archiv importujte přes Assets > Import Package > Custom Package. Po kontrole seznamu potvrďte nabídku Unity na instalaci/aktualizaci balíčkových závislostí. Počkejte na Package Manager a kompilaci. Je potřeba síť nebo potřebné balíčky Unity registry v místní cache. Odmítnutí instalace, ruční rozbalení pouze Assets či starý archiv bez metadat nezajistí potřebné assembly. Výsledné chyby kompilace neignorujte.

Archiv obsahuje oficiální metadata packagemanagermanifest/asset s pěti uvedenými balíčky. Nejde o Assets/NomadShop/package.json: package.json uvnitř Assets je informace/metadatový popis UPM, nikoli aktivní manifest projektu a sám nic neinstaluje. Nejde ani o rozšíření závislostí AssetDatabase, které může přibalit nesouvisející herní assety. Zdroje UGUI, Input System ani URP se nepřibalují.

Kontrola a obnova

Otevřete Tools > NOMAD > Dependency Status. Samostatná Editor-only assembly nezávisí na Core ani uvedených assembly. Vypíše nainstalované/chybějící balíčky, rozdíly od otestovaných verzí a aktivní URP asset. Nic skrytě neinstaluje, neaktualizuje, nesnižuje verze ani nemění globální nastavení. Pokud chybějící závislosti zabrání načtení domény Unity, nejprve obnovte balíčky přes Package Manager; nelze spoléhat na Editor skript jako opravu již rozbité kompilace.

V Window > Package Management > Package Manager zvolte Install package by name a doplňte chybějící balíčky pomocí výše uvedených identifikátorů/verzí. Před změnou zkontrolujte stávající verze; zavedený projekt naslepo nedowngradujte. Po překladu znovu otevřete kontrolu. Jiná nainstalovaná verze neznamená automatické potvrzení kompatibility.

Samotná instalace URP NEVYBERE aktivní pipeline asset. Pro demo nastavte URP v Graphics a případném Quality override běžným postupem vašeho projektu. Balíček tato nastavení nepřepisuje. Pro demo povolte Active Input Handling na Input System Package (New) nebo Both se zachováním potřeb hry. Kontrolní okno tuto podmínku vysvětluje, ale nepotvrzuje skutečné action mapy. Viz úplný rychlý start a řešení problémů. Demo stále potřebuje EventSystem s InputSystemUIInputModule.
