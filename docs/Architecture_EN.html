Architecture

The catalog defines categories and items. The UI selects an item and displays its 3D preview. The transaction service checks purchase rules and communicates with wallet and inventory adapters.

Integration boundaries

IShopBackend and ShopTransactions separate the shop from game services. IShopWallet, IShopInventory and IShopPurchaseRule are interfaces for your adapters. Persistent saving and network authority belong to the host game.
