Instalace a kontrola závislostí — RC.4

ŘEŠENÍ PROBLÉMŮ

Nejprve použijte kopii samostatného dema; neměňte originální herní systémy při diagnostice UI.

Editor nenabízí katalog

Do Catalog přetáhněte NomadCatalog .asset z Project nebo použijte Vytvořit samostatný katalog. Výběr filtruje typ NomadCatalog; prefab není katalog. Chybí-li menu, nejprve opravte chyby kompilace.

Prázdný obchod

Ověřte ID a CategoryID, zapněte Visible kategorie a přidejte správně přiřazený předmět. Pokud nic nevlastníte, přepněte MOJE VÝBAVA na VŠECHNY PŘEDMĚTY. Nový katalog je prázdný. Po strukturálních úpravách znovu otevřete UI.

Chybějící 3D model

Přiřaďte Preview.Prefab, nestačí GameplayItem nebo Icon. Zkontrolujte zapnutý MeshRenderer+MeshFilter / SkinnedMeshRenderer, materiály a Preview.LastError. Částicové či skriptem generované vizuály se nekopírují. Zkuste dodaný FieldFlask prefab.

Chybná velikost či rotace

Mimo Play upravte Preview.Scale (relativní vyplnění) a Rotation (stupně). CameraSize > 0 je minimum rámování, ne ohnisko. Zmenšete velký TargetOffset. Přepněte položku a zpět/otevřete znovu kvůli cache. Neměňte herní collidery.

Nefunguje myš, zoom či tlačítka

Aktivujte Game a táhněte levým tlačítkem uvnitř obrázku. Ověřte jeden EventSystem, InputSystemUIInputModule s Point/Click/Scroll, aktivní GraphicRaycaster a UI akce. Jiný modal nesmí zachytávat raycast a blokování hry nesmí vypnout UI.

Černá RenderTexture

V Play prověřte Preview.HasModel, Texture.IsCreated, PreviewCamera.enabled/targetTexture a volnou PreviewLayer. Ověřte URP asset v Graphics I Quality, podporované shadery a původní materiály. Po zavření jsou kamera/platforma záměrně vypnuté. Prázdný Game před Play dema je normální.

Nelze koupit

Čtěte kód: funds=zůstatek, full=CanAdd, owned=MaxPurchases, soldout=Stock/historie, locked=UnlockID/pravidlo, invalid=cena/množství/měna, unavailable=Available/objekt z katalogu/nulové zásoby. Ověřte katalog. Text Requirements není pravidlo.

Měna se neaktualizuje

backend.Balance musí číst skutečnou peněženku, ne kopii StartingBalance nebo jinou peněženku. UI kontroluje asi po 0,15 s. Ověřte potvrzený odečet a CurrencyID. Ukládaný zůstatek měňte jen potvrzenými souvislými transakcemi.

Nedoručený předmět

Prověřte TryAdd a Count(item.ID); musí vzrůst o Quantity. Při selhání Core vrací rollback a obnovuje přes adaptér. GameplayItem se automaticky neinstancuje. Demo ukládá jen počty. Před povolením skutečného zboží opravte adaptér.

Chybějící balíček či assembly

Prověřte URP/Input System/UGUI a moduly fyziky/animace v Package Manageru. Vlastní asmdef musí odkazovat na Nomad.Shop.Runtime. Kopie složky nenastaví Input Handling ani pipeline. Opravte první chybu Console a znovu otevřete editor.

Lokalizace zůstává stará

Za běhu volejte view.SetLanguage(code), ne jen přiřazení Language. Kód přidejte do Catalog.Languages; cs, nikoli cz. Přeložte obsah i catalog.Localization. Klíče vět/mezer neměňte. Přepínač editoru nemění runtime jazyk.

Růžový model / chyba URP

Použijte kompatibilní materiály (demo má Universal Render Pipeline/Lit) a aktivní URP v Graphics/Quality. Nejprve řešte chyby shaderů. Core nepřevádí cizí shadery; dodaný vlastní model pomůže odlišit problém materiálů.

Nefunguje tlačítko návodu

Počkejte na překlad/import. Documentation ponechte vedle Editor uvnitř NomadShop. Zkontrolujte hlášku o chybějícím souboru a asociaci HTML/prohlížeč. Přemístěná složka se hledá přes editorový skript; nepřesouvejte jen část produktu. HTML je lokální bez přihlášení.
