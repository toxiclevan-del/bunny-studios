TROUBLESHOOTING

First use a copy of the independent demo; do not modify production gameplay systems to diagnose the UI.

No catalog in editor

Drag a NomadCatalog .asset from Project into Catalog or use Create independent catalog. Object picker filters by NomadCatalog; a prefab is not a catalog. Fix Console compilation errors if the menu is absent.

Empty shop

Validate IDs and CategoryID, add a category with Visible on, add an item assigned through Assign category. Switch from MY EQUIPMENT to ALL ITEMS if nothing is owned. A new catalog starts empty. Reopen after structural edits.

Missing 3D model

Assign Preview.Prefab, not only GameplayItem or Icon. Check enabled MeshRenderer+MeshFilter / SkinnedMeshRenderer, material slots, and Preview.LastError. Particle-only or script-generated visuals are not previewed. Try the supplied FieldFlask prefab.

Wrong size or orientation

Outside Play adjust Preview.Scale (relative fill) and Rotation (degrees). CameraSize > 0 is minimum framing, not lens focal length. Remove excessive TargetOffset. Select another item and back/reopen to rebuild cached settings. Do not rescale gameplay colliders.

Mouse drag/zoom or buttons do not work

Focus Game view; use left drag inside the image. Ensure one active EventSystem, InputSystemUIInputModule with Point/Click/Scroll actions, active GraphicRaycaster and enabled UI actions. Check that another modal is not intercepting raycasts and gameplay input blocking did not disable UI.

Black RenderTexture

In Play check Preview.HasModel, Texture.IsCreated, PreviewCamera.enabled/targetTexture and unused PreviewLayer. Check active URP asset in Graphics AND Quality, supported shaders and original model materials. Camera/stage are intentionally disabled after close. Empty Game view before demo Play is expected.

Cannot buy

Read the actual result code: funds=balance, full=CanAdd, owned=MaxPurchases, soldout=Stock/history, locked=UnlockID/rule, invalid=price/quantity/currency, unavailable=Available/membership/stock zero. Validate catalog. Requirements text alone is not a rule.

Balance does not update

Use the real wallet via backend.Balance, not a copied StartingBalance or another wallet. UI polls about every 0.15 s. Confirm successful debit and matching CurrencyID. Only coherent committed transactions should affect saved balance.

Purchased item not delivered

Inspect TryAdd and Count(item.ID); it must increase by Quantity. Core returns rollback on failed delivery and restores via the adapter. GameplayItem is not instantiated automatically. Demo only stores counts. Fix the adapter before enabling real products.

Missing package or assembly

Check Package Manager for tested URP/Input System/UGUI versions and physics/animation modules. Custom asmdef integrations must reference Nomad.Shop.Runtime. Package folder copies alone do not configure Input Handling or render pipeline. Resolve the first Console compile error, then reopen the editor.

Localization stays in the old language

Use view.SetLanguage(code), not only Language assignment while visible. Add the code to Catalog.Languages; use cs, not cz. Translate both content and catalog.Localization table. Preserve exact UI phrase IDs/spaces. The editor toggle does not change runtime language.

Magenta model / URP error

Use compatible materials (supplied demo uses Universal Render Pipeline/Lit) and assign the active URP asset to Graphics/Quality. Check shader compilation errors first. Core does not convert third-party shaders; test a supplied original model to isolate source-material issues.

Local manual button does nothing

Wait for compile/import. Keep Documentation beside Editor inside NomadShop. Check the Console missing-file message and HTML association/default browser. A moved product folder is located via the editor script asset; do not move only half the product. HTML is offline and has no account login.
