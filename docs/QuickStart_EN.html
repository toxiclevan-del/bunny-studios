Dependency-aware import and package setup — RC.4

QUICK START — YOUR FIRST SHOP

NOMAD Shop Core 0.2.0-rc.4 · Target: roughly ten minutes once Unity and the required packages are installed. Import and shader compilation time varies; this is not a timing guarantee.

1. Prepare and import

Use a URP project. The tested combination is Unity 6000.6.3f1, Universal RP 17.6.0, Input System 1.20.0, and Unity UI 2.6.0. Other combinations have not been certified. Check these packages in Window > Package Management > Package Manager. Set Edit > Project Settings > Player > Other Settings > Active Input Handling to Input System Package (New) or Both; allow Unity's restart if requested. This changes your project's input configuration: preserve compatibility with your other systems.

Choose Assets > Import Package > Custom Package and select the supplied .unitypackage. Review the import list: product files belong under Assets/NomadShop. Import them. Wait until compilation completes; resolve Console errors before continuing. The included package.json records dependencies but a custom package import is not a substitute for checking Package Manager.

2. First purchase in the supplied demo

Open Assets/NomadShop/Demos/Scenes/NomadShop_Demo.unity. Enter Play Mode. The shop opens in English with 110 credits. Select Reactor artifact in ARTIFACTS and click BUY ITEM: the balance becomes 90, ownership becomes 1, and the purchase confirmation appears. This is a real transaction in the temporary demo inventory. Use EN / CZ, drag the model diagonally, release, use the wheel, then RESET VIEW. ESC closes; F reopens. Stop Play Mode: all demo purchases reset.

3. Create your own catalog

Outside Play Mode open Tools > NOMAD > Shop Editor. Leave the Czech editor toggle off for the English labels used below. Click Create independent catalog, choose Assets/MyShop/MyCatalog.asset (create MyShop if necessary), and save. Do not replace the supplied demo catalog. Leave generated ID values unchanged. Keep Currency ID as credits, Default Language as en, and reserve unused layer 31 for Preview Layer (choose another unused layer if your game already uses it).

Click + Add category. Expand the selected category's Element foldout, then Name. Enter Supplies for language en, Zásoby for cs. Leave Visible on. Click + Add item. Expand its definition foldout (its stable ID, or Element) and Name; enter My flask / Moje láhev. Set Price 20, Quantity 1, Available on, Max Purchases 1, Stock -1. Use Assign category to choose Supplies. Expand Preview and drag Assets/NomadShop/Demos/Prefabs/Nomad_FieldFlask.prefab from Project into Prefab. This packaged original model is a safe first preview; replace it with your own licensed prefab later. Leave preview defaults.

Assign Assets/NomadShop/Demos/NomadUILocalization.asset to the catalog's Localization field. Click Validate catalog: expect Catalog valid. Click OK, then Save catalog. The category/item names and price survive reopening the catalog. Validation checks IDs, category assignment and positive price/quantity; it does not test your game adapter.

4. Connect the demo wallet without editing the original demo

Open the supplied demo, choose File > Save As and save a copy to Assets/MyShop/MyFirstShop.unity. Select NOMAD independent demo in Hierarchy. Its NomadDemo component has a Catalog field; drag MyCatalog into it. Keep Starting Balance 110, Capacity 12 and Open At Start enabled. Save this copy. Do not add another NomadDemo or a competing EventSystem. The demo supplies a background camera and InputSystemUIInputModule if no suitable objects exist.

Enter Play. Select Supplies and My flask. Confirm the model appears, the price is 20 credits, and BUY ITEM changes 110 to 90 with owned count 1. Toggle EN/CZ: category and item translate. Drag/wheel/reset the preview. Close with ESC, reopen with F; ownership persists within that Play session. Stop Play; the demo state resets. Save catalog edits outside Play Mode.

5. Next step

Read Shop Editor for every field and Integration to connect your game's real wallet, inventory, NPC interaction and modal input boundary. NomadDemo is an example, not a second wallet to place beside your production economy. Visual guide shows the actual controls.
