NOMAD SHOP / CORE 0.2.0-rc.4

Modular RPG
Store System.

Bunny Studios presents NOMAD Shop: a modular Unity store with interactive 3D previews and room for your own RPG systems.

Start with the guides

Release candidate. This page offers no public download and makes no claim of Asset Store approval.

01

A catalog you control

Categories, prices, stock and purchase limits. Stable IDs connect items to your game.

02

Items in three dimensions

Drag to rotate, use auto-rotation, zoom and reset the view. Previewing does not run the source prefab’s gameplay scripts.

03

Your game rules

Adapters for wallets, inventories and purchase rules. Core handles the shop; your game handles persistent saving.

Product scope

A Core that fits.

Includes Shop Editor, EN/CZ localization, a standalone demo and original sample models. Additional language codes can be configured.

What your game provides

Persistent saving, production inventory and equipment, NPC interaction, input blocking and network authority are not turnkey Core game systems. Stock and purchase history live for the transaction service’s lifetime.

Tested configuration

Unity 6000.6.3f1 · URP 17.6.0 · Input System 1.20.0 · UGUI 2.6.0
