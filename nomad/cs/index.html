NOMAD SHOP / CORE 0.2.0-rc.4

Modular RPG
Store System.

Bunny Studios představuje NOMAD Shop: modulární obchod pro Unity s interaktivními 3D náhledy a prostorem pro vaše RPG systémy.

Začít s dokumentací

Release kandidát. Tato stránka nenabízí veřejné stažení ani netvrdí schválení na Asset Storu.

01

Katalog pod kontrolou

Kategorie, ceny, zásoby a limity nákupů. Stabilní ID propojují předměty s vaší hrou.

02

Předměty ve 3D

Otáčení tažením, automatická rotace, přiblížení a reset pohledu. Náhled nespouští herní skripty zdrojového prefabu.

03

Vaše herní pravidla

Adaptéry pro peněženku, inventář a podmínky nákupu. Core se stará o obchod; trvalé ukládání řeší vaše hra.

Rozsah produktu

Core, který zapadne.

Součástí jsou Editor obchodu, lokalizace EN/CZ, samostatné demo a vlastní ukázkové modely. Další jazykové kódy lze doplnit.

Co řeší vaše hra

Trvalé ukládání, produkční inventář a vybavení, interakce s NPC, blokování vstupů a síťová autorita nejsou hotové herní systémy Core. Stav zásob a historie nákupů žijí po dobu transakční služby.

Ověřená konfigurace

Unity 6000.6.3f1 · URP 17.6.0 · Input System 1.20.0 · UGUI 2.6.0
