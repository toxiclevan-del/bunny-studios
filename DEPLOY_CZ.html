Ruční zveřejnění na GitHub Pages

Web je připravený staticky. Nic nebylo publikováno ani nahráno na účet.

  1. Doplňte veřejný kontaktní e-mail v obou úvodních stránkách. Ověřte, že chcete všechny zveřejňované soubory zpřístupnit veřejnosti.
  2. Ručně vytvořte samostatný repozitář pro web. Do jeho kořene nahrajte obsah složky webu, včetně .nojekyll. Složku .qa nenahrávejte. Nikdy nenahrávejte nadřazenou složku ani Unity projekt.
  3. Na GitHubu otevřete Settings → Pages → Build and deployment → Source: Deploy from a branch. Vyberte větev main a /(root), potom Save.
  4. Po dokončení nasazení otevřete adresu uvedenou v Pages. Ověřte EN/CZ, dokumentaci, obrázky a mobilní zobrazení. Zachovejte názvy souborů a velikost písmen v cestách.
Všechny cesty jsou relativní; web lze hostovat také v podadresáři repozitáře. Lokálně otevřete index.html. GitHub Pages nezajišťuje soukromí vložených souborů.
